# C# / .NET

A collection of small applications developed as part of the coursework, covering
C# programming, desktop application development, and basic GUI technologies.

## Projects

- [Clock](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/Intro_to_specialty/Clock) — a simple clock application developed using Windows Forms.
- [ConsoleApp](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/Intro_to_specialty/ConsoleApp) — a console application for analyzing the condition of electric train carriages based on randomly generated data and determining the required maintenance actions.
- [MediaPlayer](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/Intro_to_specialty/MediaPlayer) — a desktop media player application.
- [QML](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/Intro_to_specialty/QML) — a small application demonstrating the use of QML for graphical interface development.
- [Sum](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/Intro_to_specialty/Sum) — a simple application for performing summation operations.
- [WpfApp1](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/Intro_to_specialty/WpfApp1) — a desktop application developed using Windows Presentation Foundation (WPF).
- [print(Hello World)](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/Intro_to_specialty/print%28Hello%20World%29) — a basic introductory C# application with using Windows Forms.

## Technologies

- C#
- .NET
- Windows Forms

- QML
