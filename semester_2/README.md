# Semester 2

University coursework completed during the second semester at BSU.

The semester included coursework in C++, Assembly, Qt application development,
and introductory programming.

## Main Areas

### [Assembly](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/assembly)

Practical assignments focused on low-level programming and interaction between
Assembly and C++.

Topics include:
- basic Assembly programming;
- arithmetic and logical operations;
- interaction between Assembly and C++;
- calling Assembly routines from C++ programs;
- low-level programming concepts.

### [Cross-platform application development](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/Cross_platform_cpp)

Application development using **C++ and Qt**.

The coursework includes:
- Qt application development;
- graphical user interfaces;
- event-driven programming;
- working with Qt widgets and layouts;
- connecting UI elements with application logic.

### [Introduction to Specialty](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/Intro_to_specialty)

Introductory programming assignments and small projects completed as part
of the introductory course.
