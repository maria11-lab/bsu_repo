# RGR — Assembly

A collection of three practical works focused on x86 Assembly programming
and its integration with C/C++ applications.

## Works

### RGR 1 — Integer Arithmetic

Implementation of integer arithmetic operations using x86 Assembly
integrated into a C/C++ application.

### RGR 2 — Array Processing

Implementation of array processing algorithms in x86 Assembly,
including searching, removing, and modifying array elements.

### RGR 3 — Calling Conventions

Implementation of Assembly functions using different x86 calling conventions:
`__stdcall`, `__cdecl`, and `__fastcall`.

## Technologies

- C++
- x86 Assembly
- Inline Assembly
- Calling conventions
