# Lab 1 — Variant 6

## Task

Develop a C/C++ console application with an Assembly language inline routine.

The program determines which digit occurs most frequently in the decimal representation of a given integer `N`.

## Description

The program:
- reads an integer `N`;
- analyzes its decimal digits;
- counts the frequency of each digit from `0` to `9`;
- determines the digit with the highest frequency;
- outputs the result to the console.

The main task is implemented using an **Assembly inline insertion** integrated into a C/C++ application.

## Technologies

- C++
- x86 Assembly
- Inline Assembly
