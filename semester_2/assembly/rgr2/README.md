# Lab 2 — Variant 6

## Task

Develop a C/C++ console application with an Assembly language inline routine
for processing a one-dimensional integer array.

The program finds the `N` smallest elements in the array, removes them,
shifts the remaining elements toward the beginning, and fills the remaining
positions with zeros.

## Description

The program:
- works with a one-dimensional integer array;
- finds the `N` smallest elements;
- removes the selected elements while preserving the order of the remaining elements;
- shifts the remaining elements to the beginning of the array;
- fills the remaining positions with zeros;
- outputs the resulting array.

The array processing is implemented using an **Assembly inline insertion**
integrated into a C/C++ application.

## Technologies

- C++
- x86 Assembly
- Inline Assembly
