# Cross-Platform C++

A collection of C++ projects developed as part of the cross-platform programming coursework.

## Projects

- [Bulls And Cows](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/cross_platform_cpp/BullsAndCows) — a implementation of the classic Bulls and Cows number-guessing game.
- [Calculator](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/cross_platform_cpp/Calculator) — Reverse Polish Notation calculator implemented using a stack.
- [Graphic](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/cross_platform_cpp/Graphic) — a project featuring an animation of a point moving along a graph at a variable speed.
- [TicTacToe](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/cross_platform_cpp/TicTacToe) — an implementation of the classic Tic-Tac-Toe game.
- [Two List](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/cross_platform_cpp/TwoList) — a project with drag-and-drop and the element selection system.
- [Flag](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/cross_platform_cpp/flag) — a project with two flags with adaptive sizing.
- [Flight Controller MVC](https://github.com/maria11-lab/bsu_repo/tree/main/semester_2/cross_platform_cpp/flightControlerMVC) — a flight controller application developed using the Model-View-Controller (MVC) architectural pattern.

## Technologies

- C++
- Qt
- CMake
