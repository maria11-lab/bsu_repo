# KSet

A C++ project implementing a custom set data structure with dynamic memory management and overloaded operators.

## Features

- Custom `KSet` class
- Dynamic array for storing elements
- Adding and searching elements
- Set union, intersection, and difference
- Operator overloading
- Copy constructor and assignment operator
- Custom iterator support

## Technologies

- C++
- Object-Oriented Programming
- Operator Overloading
- Dynamic Memory Management
- Iterators
