# Building

A C++ project demonstrating object-oriented programming through a simple
building management system.

## Features

- Base `Building` class and derived `House` and `Renovation` classes
- Inheritance and polymorphism
- Virtual methods and abstract interface
- Dynamic object management
- Loading data from a file
- Sorting and statistics

## Technologies

- C++
- Object-Oriented Programming
- STL
- File I/O
