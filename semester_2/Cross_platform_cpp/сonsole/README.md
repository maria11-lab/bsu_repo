# Console

A collection of C++ console projects covering object-oriented programming,
STL, data structures, file I/O, and design patterns.

## Projects

- **[AnimalShelter_DesignPatterns](https://github.com/maria11-lab/bsu_repo/edit/main/semester_2/Cross_platform_cpp/%D1%81onsole/AnimalShelter_DesignPatterns)** — project demonstrating design patterns in C++.
- **[BoutiqueDatabaseSTL](https://github.com/maria11-lab/bsu_repo/edit/main/semester_2/Cross_platform_cpp/%D1%81onsole/BoutiqueDatabaseSTL)** — database-like application using STL containers and file processing.
- **[Buildings](https://github.com/maria11-lab/bsu_repo/edit/main/semester_2/Cross_platform_cpp/%D1%81onsole/Buildings)** — object-oriented building management system with inheritance and polymorphism.
- **[FinanceDirectorySTL](https://github.com/maria11-lab/bsu_repo/edit/main/semester_2/Cross_platform_cpp/%D1%81onsole/FinanceDirectorySTL)** — finance directory using STL containers and file I/O.
- **[HotelDatabaseSTL](https://github.com/maria11-lab/bsu_repo/edit/main/semester_2/Cross_platform_cpp/%D1%81onsole/HotelDatabaseSTL)** — hotel data management using STL containers.
- **[KSet](https://github.com/maria11-lab/bsu_repo/edit/main/semester_2/Cross_platform_cpp/%D1%81onsole/KSet)** — custom set implementation with operator overloading and iterator support.
- **[StudentDatabaseSTL](https://github.com/maria11-lab/bsu_repo/edit/main/semester_2/Cross_platform_cpp/%D1%81onsole/StudentDatabaseSTL)** — student data management using STL containers.
- **[StudentSessionManagement_OOP](https://github.com/maria11-lab/bsu_repo/edit/main/semester_2/Cross_platform_cpp/%D1%81onsole/StudentSessionManagement_OOP)** — object-oriented student and session management system.
- **[Wallet](https://github.com/maria11-lab/bsu_repo/edit/main/semester_2/Cross_platform_cpp/%D1%81onsole/Wallet)** — custom wallet class demonstrating operator overloading and exception handling.

## Technologies

- C++
- Object-Oriented Programming
- STL
- Data Structures
- Operator Overloading
- File I/O
- Design Patterns
