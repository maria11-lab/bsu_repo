# Console

A collection of C++ console projects covering object-oriented programming,
STL, data structures, file I/O, and design patterns.

## Projects

- **AnimalShelter_DesignPatterns** — project demonstrating design patterns in C++.
- **BoutiqueDatabaseSTL** — database-like application using STL containers and file processing.
- **Buildings** — object-oriented building management system with inheritance and polymorphism.
- **FinanceDirectorySTL** — finance directory using STL containers and file I/O.
- **HotelDatabaseSTL** — hotel data management using STL containers.
- **KSet** — custom set implementation with operator overloading and iterator support.
- **StudentDatabaseSTL** — student data management using STL containers.
- **StudentSessionManagement_OOP** — object-oriented student and session management system.
- **Wallet** — custom wallet class demonstrating operator overloading and exception handling.

## Technologies

- C++
- Object-Oriented Programming
- STL
- Data Structures
- Operator Overloading
- File I/O
