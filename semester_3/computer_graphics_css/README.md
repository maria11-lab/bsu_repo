# Computer Graphics

University practical works and laboratory assignments in **Computer Graphics** completed as part of the university curriculum.

This section contains practical applications developed to study the fundamental principles of computer graphics, color representation and processing, as well as algorithms and methods used when working with graphical data.

Unlike small standalone tasks, the laboratory works are presented as independent applications with graphical user interfaces. Each work focuses on a specific topic of the course and includes source code, implementation details, and examples of the program in operation.
