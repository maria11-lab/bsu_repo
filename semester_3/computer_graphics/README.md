# Computer Graphics

Учебные проекты и лабораторные работы по дисциплине **Computer Graphics**, выполненные в рамках университетской программы.

В этом разделе собраны практические приложения, разработанные для изучения основных принципов компьютерной графики, представления и обработки цветовой информации, а также алгоритмов и методов, используемых при работе с графическими данными.

В отличие от небольших отдельных задач, лабораторные работы представлены в виде самостоятельных приложений с пользовательским интерфейсом. Каждая работа посвящена отдельной теме курса и содержит исходный код, описание реализации и примеры работы программы.

## Project Structure

Каждая лабораторная работа размещена в отдельной директории и представляет собой самостоятельное приложение.

```text
computer_graphics/
│
├── rgb_hls_cmyk_converter_lab1/
│   └── README.md
│
├── ...
│
```

В директории каждой лабораторной работы находятся исходный код приложения и документация с описанием задания, используемых алгоритмов, особенностей реализации и примерами работы.

## About

Основная цель лабораторных работ — практическое применение методов компьютерной графики и разработка небольших самостоятельных приложений на C#.

Работы выполняются последовательно в рамках учебного курса и по мере выполнения добавляются в данный раздел репозитория.
