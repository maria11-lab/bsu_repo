# Отчёт по лабораторной работе №1
## Разработка конвертера цветовых моделей RGB / HLS / CMYK (WPF, MVVM)

### Цели проекта и техническая реализация

Целью разработки являлось создание настольного WPF-приложения для одновременного представления и интерактивного преобразования цвета в пространствах RGB, HLS и CMYK с обеспечением строгой двусторонней синхронизации параметров. Архитектурно приложение построено на паттерне MVVM, где взаимодействие элементов управления (ползунков и текстовых полей) с данными реализовано через механизм привязки данных (`Binding`) к свойствам класса `MainViewModel` без применения избыточного процедурного кода. Бизнес-логика вынесена в независимый проект `lab1.Core`, содержащий статические модули `HlsConverter` и `CmykConverter` для математических расчетов, в то время как промежуточные преобразования между HLS и CMYK осуществляются через базовое цветовое пространство RGB. Дополнительно интерфейс включает системную палитру Windows, визуальный индикатор цвета и элементы управления для настройки алгоритмов расчета черного канала (*Naive*, *Ucr*, *Gcr*) с регулировкой коэффициента силы.

### Проблемы синхронизации и их решение

В процессе разработки возникла технологическая сложность: при любом изменении параметра система производила принудительный пересчет всех цветовых моделей из RGB-пространства. Это вызывало артефакты в виде сброса оттенка и насыщенности при приближении ползунка яркости к экстремальным значениям белого или черного, а также дестабилизацию текстовых полей при вводе чисел с клавиатуры. Для устранения этих недостатков был внедрен паттерн «Наблюдатель» в сочетании с механизмом контроля источников изменений. Введение переменной-флага позволяет фиксировать инициатора модификации и блокировать для него циклический обратный пересчет, полностью исключая эффект «плавания» значений. Кроме того, обработка ввода в текстовых полей была оптимизирована за счет переноса срабатывания событий на момент потери фокуса или нажатия клавиши `Enter`.

### Верификация математической модели

Для гарантии корректности вычислительного ядра и предотвращения ошибок при дальнейших модификациях был разработан комплекс модульных тестов на базе фреймворка xUnit. Автоматизированные проверки охватывают корректность обработки опорных базовых цветов (например, соответствие чистых RGB-компонент параметрам HLS и CMYK), стабильность работы всех трех алгоритмов формирования черного канала, а также сквозные циклы преобразований по полному пути HLS → RGB → CMYK.

### Вывод

В результате выполнения лабораторной работы было успешно разработано и протестировано настольное WPF-приложение, реализующее синхронное двустороннее преобразование цветов в моделях RGB, HLS и CMYK. Применение архитектурного шаблона MVVM, паттерна «Наблюдатель» для устранения циклических пересчетов, а также комплексное модульное тестирование на базе xUnit позволили создать отказоустойчивую и расширяемую структуру программного обеспечения, полностью решающую поставленные задачи.
