# Цветовые модели: RGB ↔ HLS ↔ CMYK

Лабораторная работа №1 по курсу компьютерной графики. WPF-приложение (.NET 8) для интерактивного просмотра и преобразования цвета одновременно в трёх моделях: **RGB**, **HLS** и **CMYK**.

## Возможности

- Одновременное отображение цвета в трёх моделях с автоматическим пересчётом: изменение любого параметра (в RGB, HLS или CMYK) мгновенно обновляет два других представления.
- Три способа задать цвет:
  - точный ввод числа в текстовое поле для каждого канала;
  - плавное изменение ползунком;
  - выбор из системной палитры Windows (кнопка «Выбрать из палитры…»).
- Живой предпросмотр текущего цвета.
- Для перевода в CMYK — выбор алгоритма цветоделения:
  - **Naive** — прямой перевод без замены серой составляющей;
  - **UCR** (Under Color Removal) — удаление CMY-компонентов в тенях с заменой на чёрный;
  - **GCR** (Gray Component Replacement) — замена серой составляющей на чёрный во всём диапазоне;
  - регулировка силы алгоритма ползунком (для UCR/GCR).
    
## Архитектура

Проект построен по паттерну MVVM и разделён на две сборки:

```
src/
├── lab1.Core/                  # Model — чистая математика, без зависимостей от UI
│   └── Models/
│       ├── HlsConverter.cs     # RGB <-> HLS
│       ├── CmykConverter.cs    # RGB <-> CMYK (Naive / UCR / GCR)
│       └── ColorMathTests.cs   # самопроверка конвертеров
│
└── lab1/                       # View + ViewModel (WPF)
    ├── MainWindow.xaml         # интерфейс: карточки RGB / HLS / CMYK, палитра, превью
    ├── MainWindow.xaml.cs      # code-behind: диалог палитры, Enter в текстовых полях
    └── ViewModels/
        ├── MainViewModel.cs    # связывает интерфейс с lab1.Core, хранит состояние
        └── RelayCommand.cs
```

`lab1.Core` не знает о существовании WPF и может быть переиспользован (например, в тестах или в другом UI). Вся логика синхронизации между моделями и защита от циклов пересчёта находится в `MainViewModel`.

## Сборка и запуск

**Требования:** Windows, .NET 8 SDK (или Visual Studio 2022+ с workload «.NET desktop development»).

Через Visual Studio:
1. Открыть `lab1.sln`.
2. Установить `lab1` как стартовый проект (обычно уже так по умолчанию).
3. Запустить (F5) или собрать Release-версию через Build → Publish.

Через консоль:
```bash
cd src/lab1
dotnet run
```

Готовый `.exe` после сборки лежит в `src/lab1/bin/Debug/net8.0-windows/lab1.exe`.
